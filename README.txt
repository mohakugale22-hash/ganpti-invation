# Ganpati Invitation Website

## Files
- index.html
- style.css
- ganpati-photo.jpg

## How to create your invitation link using GitHub Pages
1. Open https://github.com and sign in.
2. Create a new repository named `ganpati-invitation`.
3. Upload `index.html`, `style.css`, and `ganpati-photo.jpg`.
4. Open the repository's **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/root`, then save.
8. Wait a little. GitHub will show your public invitation link.

## Easy alternative: Netlify
1. Open https://app.netlify.com/drop
2. Drag the whole `ganpati_invitation` folder into the page.
3. Netlify will generate a public link.
4. Share that link on WhatsApp.

Note: The Google Maps button opens a search for the supplied location. Check the exact pin before sharing.
